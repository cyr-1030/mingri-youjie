# 明日有解

把此刻最关心的事，整理成今天或明天可以照着做的行动与穿搭方案。

**在线使用：** <https://cyr-1030.github.io/mingri-youjie/>

## 怎么使用

1. 选择今天或明天，以及此刻最在意的主题。
2. 想象三幕场景，按第一反应选择，不需要提前想好答案。
3. 从图中挑选第一眼最想靠近的物件，查看对应的提醒。
4. 补充所在城市、场合和喜欢的风格，天气会自动更新。
5. 查看行动、穿搭、妆容和准备清单；也可以先在「我的」中录入已有衣物。

## 可以使用的内容

- **明日签：**通过意象互动梳理当下状态，得到具体行动提醒。
- **答案书：**带着一个问题翻开一页，把回答当作下一步的小提示。
- **命盘：**填写出生日期、可选时刻和地区，查看四柱五行与可计算的星体位置。
- **方案：**结合天气、场合、风格和衣橱，生成可以直接准备的穿搭与妆容清单。
- **我的：**记录常穿单品与照片，整理未来可以逐步补充的衣橱缺口。

## 资料与隐私

出生资料、偏好和衣橱默认只保存在当前浏览器，不会公开展示；可选项目可以跳过，也可以随时删除。详细说明见[隐私说明](https://cyr-1030.github.io/mingri-youjie/privacy.html)。

传统文化与象征内容用于自我观察和生活灵感，不用于预测事件，也不替代医疗、心理、法律或财务等专业意见。天气与实际出行请以当地权威信息为准。
