# 明日穿什么｜微信公开版

这是从「明日有解」完整体验版分离出的微信公开版，保留天气、场景问答、直觉选物、风格偏好、衣橱和具体穿搭方案。

## 与完整体验版的区别

公开版已移除出生资料、传统命理、黄历、星盘、预测性表达、外部博主主页和站外内容链接。用户的选择只用于整理场景偏好与生成穿搭建议。

## 运行

1. 在微信开发者工具中导入本目录。
2. 选择云环境并部署 `cloudfunctions/getForecast`。
3. 在云函数环境变量中配置 `CAIYUN_API_TOKEN`，不要把令牌写进源码。
4. 执行 `npm test` 验证公开版文案、推荐链路和天气接口。

## 发布前

- 在微信公众平台完成小程序名称、头像、简介、服务类目和备案。
- 在「用户隐私保护指引」中说明相册或相机图片、本地衣橱资料、城市与天气的用途。
- 使用真实手机验证城市天气、相册授权、缓存删除和全部九个场景。
- 提交审核前再次核对微信公众平台当时可选的服务类目与审核规范。

完整传统文化体验保留在仓库 `main` 分支；此版本位于 `wechat-public` 分支。
